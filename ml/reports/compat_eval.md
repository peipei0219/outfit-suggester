# コーデ相性モデルの評価（Polyvore Outfits, disjoint）

- データ: Polyvore Outfits（Vasileva et al., ECCV 2018）の disjoint 分割。train / valid / test でアイテムが重ならない
- 対象: アプリの種類に入るアイテム（アウター・トップス・ボトムス）だけ。靴・バッグ・ワンピースなどは除外
- 入力: CLIP の画像埋め込み（ブラウザと同じ量子化 ONNX）。学習の組: {'outer/bottoms': 8883, 'tops/bottoms': 27750, 'outer/tops': 8754}（負例は正例の 2 倍）
- 問題数: valid FITB 738 / 相性判定 3272、test FITB 3783 / 相性判定 16110
- **FITB**: コーデの空欄に入るアイテムを 4 択で当てる（ランダムなら 25%）
- **相性判定 AUC**: 本物のコーデと、アイテムをランダムに入れ替えたコーデを見分ける（ランダムなら 0.5）
- 公式の数値（全カテゴリを使う）とは問題の範囲が違うので直接は比べられない

## 結果（test）

| モデル | FITB 正解率（95% 信頼区間） | 相性判定 AUC |
|---|---:|---:|
| ランダム | 25.8%（±1.4%） | 0.501 |
| CLIP の類似度（学習なし） | 36.9%（±1.5%） | 0.594 |
| ロジスティック回帰（種類の組ごと）（C=0.1） | 38.3%（±1.5%） | 0.620 |
| ニューラルネット（MLP）（h=128 a=0.0001） | 40.8%（±1.6%） | 0.657 |

アプリに採用: **mlp h=128 a=0.0001**（valid の FITB で選択）

## ハイパーパラメータの選択（valid）

| 設定 | FITB | AUC |
|---|---:|---:|
| logistic C=0.1 | 38.8% | 0.609 |
| logistic C=1.0 | 37.7% | 0.624 |
| logistic C=10.0 | 37.0% | 0.624 |
| mlp h=64 a=0.0001 | 37.8% | 0.625 |
| mlp h=64 a=0.01 | 37.5% | 0.623 |
| mlp h=128 a=0.0001 | 39.3% | 0.642 |
| mlp h=128 a=0.01 | 39.3% | 0.619 |

## アプリでの「相性」の表示基準

valid の本物のコーデのスコア中央値（-0.546）以上を「◎」、入れ替えたコーデの中央値（-0.829）未満を「△」、その間を「○」とする。
